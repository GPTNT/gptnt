# Configuration reference

Configuration pages identify editable fields, environment values, defaults, and ownership. They
link back to the procedure that consumes each value.

## Available configuration

| Configuration | Use it for |
| ------------- | ---------- |
| [Environment](environment.md){data-preview} | Paths, runtime endpoints, display, KTANE settings, observability, and service timeouts |
| [Run manifest](../../running/run-your-model.md#declare-a-run) | Suites, rooms, players, displays, anchors, completion source, and attempts |
| [Manuals](../../manuals.md) | Manual profiles, source pins, compilation, and cache use |

Player, provider, suite, mission, manual-schema, and module-registry reference joins this section
with its connected model-integration and execution pages.
