# Configuration reference

Configuration pages identify editable fields, environment values, defaults, and ownership. They
link back to the procedure that consumes each value.

## Available configuration

| Configuration | Use it for |
| ------------- | ---------- |
| [Environment](environment.md){data-preview} | Paths, runtime endpoints, display, KTANE settings, observability, and service timeouts |
| [Run manifest](run-manifest.md){data-preview} | Suites, rooms, players, displays, anchors, completion source, observability, and attempts |
| [Players](players.md){data-preview} | Identity, capabilities, model attachment, processing, and operational configuration |
| [Providers](providers.md){data-preview} | Provider override composition and validation boundaries |
| [Manuals](manuals.md){data-preview} | Profile variants, source pins, language constraints, and the current rule-seed boundary |

Suite, mission, and module-registry reference joins this section with its connected authoring
procedures.
